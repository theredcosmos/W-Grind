# Project Constitution (gemini.md)

## Data Schemas
Generated by `tools/import_xlsx.py` from the DSA master workbook (see `architecture/import_questions.md`).

`app/src/data/questions.json` — one record per unique problem:
```json
{
  "id": "string (LeetCode slug, natural key, e.g. 'two-sum')",
  "n": "int (Master Q# from the workbook)",
  "title": "string",
  "url": "string (https://leetcode.com/problems/<slug>/)",
  "difficulty": "Easy | Medium | Hard",
  "week": "string (12-week plan bucket)",
  "section": "string (e.g. 'Arrays', 'Graphs')",
  "topic": "string (sub-topic, e.g. 'Two Pointers')",
  "pattern": "string (core pattern)",
  "trigger": "string (ADHD anti-blank trigger: what to spot in the prompt)",
  "linker": "string (DSA elements & how to link them)",
  "lists": ["blind75 | neetcode150 | top150 | striver"],
  "also": ["string (optional: other sub-topics this problem is listed under)"]
}
```

`app/src/data/lists.json` — `{ blind75|neetcode150|top150|striver: { name, short, items: [{ id, group }] } }`, items in sheet order.
`app/src/data/manual.json` — `{ antiBlank|decoder|linker: { title, headers, rows: [[string]] } }`.
`app/src/data/legacyIds.json` — `{ "<old numeric id>": "<slug>" }` used to migrate saved progress.

User progress (localStorage; `completed` + `trackedTime` also sync to the backend):
```json
{
  "completedQuestions": { "<slug>": "YYYY-MM-DD" },
  "reviews": { "<slug>": { "r7": "YYYY-MM-DD", "r14": "YYYY-MM-DD" } },
  "notes": { "<slug>": "string" },
  "trackedTime": { "YYYY-MM-DD": "seconds" }
}
```

Auth & preferences (localStorage):
```json
{
  "session": { "username": "string", "mode": "cloud | offline", "token": "string (HS256 signed, 30-day, cloud only)" },
  "offlineAccounts": { "<lowercased name>": { "username": "string", "salt": "hex", "hash": "hex (PBKDF2-SHA256, 210k iterations)" } },
  "uiTheme": "system | gotham | sakura | tide | aurora | zen",
  "ambientMotion": "on | off",
  "u:<username>:<key>": "per-user progress (completedQuestions, reviews, notes, trackedTime, randomSeen, equippedTitle)"
}
```
Lore (derived in `app/src/lib/lore.js`, never stored): section → Gate (`GATE_NAMES`), topic → Floor N (sheet order),
question → Monster `{ name, kind }` generated deterministically from the slug (names unique, original — no franchise terms).

Server: `POST /api/login|register|google-auth` → `{ username, token }`. `GET|POST /api/sync` require `Authorization: Bearer <token>`.
Env: `AUTH_SECRET` (required in production), optional `FIREBASE_API_KEY`, `CORS_ORIGIN`.

## Behavioral Rules
- System Pilot Identity: Prioritize reliability over speed, deterministic self-healing automation.
- B.L.A.S.T Protocol: Blueprint, Link, Architect, Stylize, Trigger.
- A.N.T 3-Layer Architecture: Architecture (SOPs), Navigation (Decision Making), Tools (Python scripts).
- Data-First Rule: Define JSON Data Schema before building any tools.
- Deliverables vs Intermediates: Local `.tmp/` for intermediates, Global for Payload.

## Architectural Invariants
- Layer 1: SOPs in markdown.
- Layer 2: Routing via LLM.
- Layer 3: Deterministic python scripts in `tools/`.
- No scripts in `tools/` until Discovery and Schema are defined.
- Errors must be analyzed, patched, tested, and architecture updated.
